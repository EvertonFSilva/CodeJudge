# Problema: Análise de String e Verificação de Palíndromo

O algoritmo recebe uma sequência de caracteres (string sem espaços em branco) e realiza três operações fundamentais de processamento de texto.

## Operações
1. **Comprimento**: Contabiliza o número total de caracteres da palavra.
2. **Inversão**: Gera a representação invertida da string original (preservando o case).
3. **Palíndromo**: Determina se a palavra é idêntica quando lida de trás para frente, de forma insensível a maiúsculas/minúsculas (case-insensitive).

## Formato de Entrada
Uma palavra por linha sem espaços em branco.

## Formato de Saída
Uma única linha no padrão:
`Tam=<comprimento> Invertida=<string_invertida> Palindromo=<SIM|NAO>`
