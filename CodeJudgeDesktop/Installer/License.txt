2. FINALIDADE ACADÊMICA E PEDAGÓGICA
O CodeJudge foi desenvolvido para avaliação automatizada de códigos-fonte,
execução de baterias de testes com entrada/saída padronizadas e diagnóstico
educacional assistido por Inteligência Artificial (Ollama / IA Generativa).

3. REQUISITOS DO SISTEMA
- Sistema Operacional: Microsoft Windows 10 (versão 1809 ou superior) ou Windows 11 (64-bit).
- Microsoft Edge WebView2 Runtime (geralmente pré-instalado no Windows 10/11).
- Python 3.10 ou superior (para execução do motor backend CodeJudgeApp e testes locais).
- Compiladores das linguagens desejadas (GCC/G++ para C/C++, JDK para Java, Python 3).
- (Opcional) Ollama instalado localmente com modelos como llama3:latest ou deepseek-coder
  para geração de análises inteligentes e tutoria automatizada de código.

4. POLÍTICA DE PRIVACIDADE E DADOS LOCAIS
O CodeJudge preza pela privacidade acadêmica e segurança dos estudantes. A execução
de código e a análise por meio de modelos locais (Ollama) ocorrem integralmente no
ambiente local do usuário, sem transmissão não autorizada de dados para servidores
externos de terceiros.
